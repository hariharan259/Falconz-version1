# FalconZ Knowledge Base

This directory contains curated engineering knowledge documents for FalconZ AI.

## Document Format
Each document MUST follow strict Markdown formatting with a YAML-style frontmatter section containing metadata.

Example:
```markdown
---
id: example-doc
title: Example Document
category: CATEGORY_NAME
source: FalconZ Knowledge Base
sourceType: INTERNAL_REFERENCE
version: 1.0
---

# Title
...
```

## Safety Rule
Do NOT populate the knowledge base with made-up technical specifications or numbers.
If a fact comes from a manufacturer manual or official documentation, preserve the source.
Do not label general engineering knowledge as a manufacturer specification.
